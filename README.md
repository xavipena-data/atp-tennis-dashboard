ATP Tennis Dashboard

Interactive HTML dashboard exploring the history of men's professional tennis (Open Era, 1968 onwards) using public ATP match data.

Work in progress. Part of my data portfolio at xavipena.com.

Data

Match, ranking and player data come from Jeff Sackmann's tennis_atp repository.

The data is licensed under Creative Commons Attribution-NonCommercial-ShareAlike 4.0. Derived data in this repository keeps the same license. Raw files are not included in this repo and must be downloaded separately.
