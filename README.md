# ATP Tennis Dashboard

Interactive HTML dashboard exploring the history of men's professional tennis (Open Era, 1968 onwards) using public ATP match data.

> Work in progress. Part of my data portfolio at [xavipena.com](https://xavipena.com).

## Data

Match, player and ranking data come from the [TML-Database](https://github.com/Tennismylife/TML-Database) and the [TML-Rankings-Database](https://github.com/Tennismylife/TML-Rankings-Database) by Tennismylife. TML-Database is originally inspired by Jeff Sackmann's tennis_atp project, which was released under [Creative Commons Attribution-NonCommercial-ShareAlike 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). Credit for the original dataset goes to Jeff Sackmann / Tennis Abstract.

This is a non-commercial, educational portfolio project. Raw files are not included in this repository: they are downloaded with `src/download_data.py`. Derived data in this repository keeps the same non-commercial, share-alike terms.
